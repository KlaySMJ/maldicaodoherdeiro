# Ilustrações aplicadas

As artes geradas para esta etapa foram movidas para `assets/` e conectadas ao jogo em PNG com fundo transparente. Os SVGs anteriores foram mantidos no projeto.

- `assets/herdeiros/`: bustos dos três traços, cada um com sete fases de honra e uma roupa especial de culto.
- `assets/eventos-especiais/` e pastas de eventos: ilustrações específicas.
- `assets/`: ilustrações genéricas compartilhadas.

A pasta permanece como registro da etapa de criação; os arquivos em uso estão em `assets/`.
